## AI Configuration

### providers.json
Defines LLM providers with connection details: npm SDK type, base URL, and API key.
Each provider is keyed by ID (e.g., "zai", "openrouter", "ollama").

### models.json
Flat model list. Each model references a provider by ID and specifies the actual model name sent to the API.
Optional overrides: `maxTokens`, `temperature`, `_local`.

Override chain: agent config → model config → provider config → hardcoded defaults.

### main_agent.json
Configures the orchestrator agent with model, tools (boolean map), max parallel sub-agents, and prompt path.

### sub_agents.json
Configures 4 sub-agents keyed by name:
- `latex-writer` - Writing and editing content
- `bibtex-manager` - Bibliography and citations
- `error-fixer` - Fixing compilation errors
- `format-checker` - Formatting issues

Each sub-agent has its own model (empty = inherit), tools map, and prompt path.

### prompts/
System prompts for each agent. Customize to change agent behavior.

## Keyboard Shortcuts

Edit `shortcuts.json` to define custom keyboard shortcuts.

### Default Shortcuts

| Key (macOS) | Command | Description |
|-------------|---------|-------------|
| `Cmd+B` | Toggle bold | `\textbf{}` |
| `Cmd+I` | Toggle italic | `\textit{}` |
| `Cmd+Enter` | Build and view | Build + preview PDF |

### Available Commands

**Text Formatting:** `latex-ai-tool.shortcut.textbf`, `textit`, `emph`, `underline`, `textrm`, `texttt`, `textsl`, `textsc`, `textnormal`, `textsuperscript`, `textsubscript`

**Math Formatting:** `latex-ai-tool.shortcut.mathbf`, `mathit`, `mathrm`, `mathtt`, `mathsf`, `mathbb`, `mathcal`

**Build:** `latex-ai-tool.build`, `buildAndView`, `recipes`, `kill`, `clean`

**View:** `latex-ai-tool.view`, `viewInBrowser`, `viewExternal`, `tab`, `refresh-viewer`

**Navigation:** `latex-ai-tool.synctex`, `navigate-envpair`, `select-envname`, `select-envcontent`, `close-env`, `wrap-env`

**Bibliography:** `latex-ai-tool.citation`, `bibsort`, `bibalign`, `bibalignsort`, `checkcitations`

### Adding New Shortcuts

```json
{
  "id": "underline",
  "key": "cmd+u",
  "when": "editorTextFocus && !editorReadonly && editorLangId =~ /^latex$/",
  "command": "latex-ai-tool.shortcut.underline",
  "description": "Toggle underline"
}
```

Changes are applied immediately (hot-reload).
